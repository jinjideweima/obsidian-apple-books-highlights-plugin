# 设置说明

## 导入目录

- 默认值：`ibooks-highlights`

保存 Apple Books 书籍主笔记和摘录卡片的 Vault 内目录。支持嵌套路径，例如：

- `notes/highlights`
- `3 - Resources/My Books/Apple Books`

如果路径不存在，插件会自动创建。

## 启动时导入

- 默认值：关闭

Obsidian 启动时自动导入所有 Apple Books 摘录。遵循备份设置。

## 导入前备份

- 默认值：关闭

导入前备份已有内容，防止数据丢失。

- 全部导入时：复制整个导入目录 → `<导入目录>-bk-<时间戳>`；不再移动原目录。
- 单本导入也保存完整目录快照，包含卡片和封面；目录外的本地封面额外保存在快照的 `.external-covers/` 中。

> [!TIP]
> 导入直接合并来源更新，保留人工属性和正文；不再使用整篇覆盖确认。只有清理已移除摘录时显示删除确认。

## 备份保留份数

- 默认值：全部保留

每次开启备份的导入都会生成一份完整快照；开启「启动时导入」时，每次启动 Obsidian 都会多一份。选择「最近 N 份」后，导入完成备份时会把更早的快照按 Obsidian「文件与链接 → 删除文件」的设置移走（默认进入回收站）。只处理名称为 `<导入目录>-bk-<数字>` 的插件快照，不会动其他文件夹；清理失败时保留全部快照，并在导入结果中提示。

## 每日新摘录数

- 默认值：10 条

「今日回顾」每天最多加入几条从未回顾过的摘录（收藏的优先）。已经回顾过、今天到期的摘录不受这个数量限制。完成当天的回顾后，可以在面板里点「再学 5 条新摘录」。

回顾记录保存在每张摘录卡片的属性中（`review_due`、`review_stability` 等），重新导入不会清除，也可以在 Base 里按到期日查询。不想再看到的摘录，可以在「⋯」菜单里选择「不再出现在每日回顾」。

## 摘录顺序

摘录始终按在书中的位置排列，新增、移出、恢复时连续编号；筛选和随机展示沿用原编号。旧版本的「摘录排序方式」设置已移除。

## 书籍主笔记模板

使用 Handlebars + Markdown 自定义每本书主笔记的输出格式。独立摘录卡片由插件自动生成，不受此模板影响。

详见 [模板与变量](/customization/templates-and-variables)。

## 个人内容的保留

重新导入不会整篇重写书籍主笔记：正文（如「我的读书笔记」下的读后感）和你手动修改过的属性都会保留，只更新摘录目录和卡片嵌入区域。因此不再需要旧版的保留区（Keep Me）分隔符，该设置已移除；已有笔记中的 `%% keep-me %%` 标记可以保留，也可以删除，不影响导入。

## 书籍主笔记文件名模板

## 封面路径模板

<span v-pre>

- 默认值：留空

插件会从 EPUB 文件里自动提取封面图。这个模板控制封面图**保存到 Vault 内的哪个路径**（相对 Vault 根目录，不含扩展名）。

- **留空**：封面保存到 `<导入目录>/covers/<书名>`
- **自定义**：例如填 `附件/书封/{{{bookTitle}}} - {{{bookAuthor}}}`，封面就保存到 `附件/书封/书名 - 作者.<扩展名>`

可用变量：`{{{bookTitle}}}`、`{{bookId}}`、`{{{bookAuthor}}}`、`{{{bookGenre}}}`、`{{bookLanguage}}`

</span>

> [!TIP]
> 扩展名会自动跟随封面的真实格式（jpg / png / webp …），书籍主笔记 frontmatter 里的 `cover` 字段也会同步指向它——图片和引用始终一致，无需手动转换格式。

> [!NOTE]
> 仅对**无 DRM 的 EPUB**（侧载书、多数非商店购买书）有效。在 macOS 上，若书籍存放在 iCloud，需要给 Obsidian 授予「完全磁盘访问」权限才能读取。

## 重置模板

将书籍主笔记模板恢复为默认值。
